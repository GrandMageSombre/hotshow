# 直播源精选：从 3156 条筛到 111 台

> 更新时间：2026-11-05
> 结论：**运行时拉公开源这条路不可行，改成内置一份全量实测过的精选目录。**

## 一、为什么改

第一版直播页是「运行时从 GitHub 拉 7 份公开 m3u，合并去重后给用户」。
上线后收到的反馈是「很多直播源都播放失败」。

查下去发现两个层面都有问题：

**1. 公开源本身就烂。** 全量实测 3156 个地址，只有 897 条能播（28%）。
那个号称「1300 个直播源全部有效」的合集，1298 条里只有 **8 条**能播。

**2. 我们的检测方法不对，比源本身的问题更致命。**

- 检测用的 UA 是自己编的 Android Chrome，而 App 里 libmpv 发的是
  `kBrowserUserAgent`（Windows Chrome）——有些 CDN 按 UA 放行，
  「我测着能播、用户播不了」；
- 检测时没带 Referer，App 的 `_headersFor` 却会自动补同域 Referer——
  直播 CDN 上多一个 Referer 反而常被判盗链；
- 只验了主列表，没验 `#EXT-X-KEY`（AES-128 流拿不到 key 会黑屏）；
- 只验第一个分片，没验后面的（「列表正常、后续分片全死」完全测不出来）。

## 三、筛成什么样

1. **同台归并**：`CCTV-1` / `CCTV1` / `CCTV-1 综合` / `CCTV1 HD` 归一成一台，
   按响应速度排序，最多留 3 个地址（主地址 + 备用线路）。
2. **白名单收敛**：只留用户要的四类——
   - **央视** 26 台：CCTV-1～17 + CCTV-5+ + CGTN 系列
   - **地方** 37 台：31 个省/直辖市/自治区卫视 + 深圳/大湾区/延边/兵团/安多/香港
   - **国外** 17 台：凤凰 3 台、翡翠台、美亚、TVBS、台视、NHK、日本电视台、
     东京电视台、Arirang、TBS 韩国、KTV、TV Chosun、Weathernews、原住民
   - **体育** 31 台：NBA TV、纬来体育、精品体育、足球频道、Sky Sports、
     Eurosport、ESPN、Fox Sports、NBC Sports、beIN、NHL、网球、高尔夫、
     MUTV、Milan TV、Real Madrid TV、DAZN、Eleven、Arena Sport…
3. **剔掉垃圾台**：本地频道（浙江遂昌、河北农民…）、购物台（GS Shop、
   Lotte Home Shopping…）、宗教台、`HLxx-DTV` 这种韩国地方台。
4. **规范化台名**：CCTV 系列补中文名（CCTV-1 综合），去掉 `(1080p)` 后缀。

最终 **111 台 / 215 个地址**，写进 `assets/live_channels.json`（25KB）。

## 四、稳定性怎么保证

- **每个台最多 3 个地址**：央视 19/26、地方 33/37 有备用地址；
- **自动切换**：`PlayerPage._tryNextLiveLine()` 在主地址起播失败时，
  自动顺延到下一个备用地址，用户在播放器里也能手动切；
- **复验不误杀**：复验时单次失败会重试，重试仍失败但首轮通过过的台**保留**
  （实测同一批台连跑两次，掉的台不是同一批，属于抖动）。

## 五、会过期，怎么更新

直播地址通常几个月就变一批。用户反馈「某个台打不开」且不是个例时重跑：

```bash
# 1. 全量检测（约 30 分钟，结果写 tool/live_verify/out/result.jsonl）
python tool/live_verify/verify.py

# 2. 归并 + 分类 + 白名单 + 复验（会重写 assets/live_channels.json）
python tool/live_verify/curate.py
```

脚本在 `tool/live_verify/`，`README.md` 里写了细节。跑完记得同步本文的数字。

## 六、踩过的坑

- **不要用 `split(',', 1)[-1]` 取台名**：`#EXTINF` 行里可能嵌
  `http-user-agent="…(Windows NT 10.0; Win64; x64)…"`，UA 自带逗号，
  按第一个逗号切会把 UA 碎片当台名。必须用「第一个引号外逗号」。
- **抽样不等于全量**：同一份源抽样 40 个测出 80% 可播，全量只有 43%。
- **检测必须复刻 App 的请求头**，否则测出来的数字没有意义。
- **`Not 24/7` 标记的台**大多是购物/宗教频道，能播但没内容价值。
