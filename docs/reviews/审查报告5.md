# 审查报告 5 — v1.6.0（iOS 平台 + 无 Mac 出包链路）

- 审查时间：2026-10-28
- 审查对象：新增 `ios/` 平台工程、GitHub Actions 未签名 IPA 工作流、README「在 iPhone 上运行」章节
- 审查方式：4 个子智能体并行。**C（CI 可靠性）、B（签名/安装）、D（文档体验）按时返回**；
  A（iOS 构建链路）超时未返回，已终止，该视角由主控自查补足（见第四节）
- 验证结果：`flutter analyze` 0 问题；`flutter test` 127/127（Dart 代码未改）；
  **iOS 构建未在本机验证**（Windows 无 Xcode），首次实际出包需跑一次 Actions
- 结论：方案在「只有 iPhone + Windows」的约束下成立，但有两个必须说清的前提 ——
  ①编译必须借助 macOS（本方案用 GitHub 免费 runner）；②免费 Apple ID 签名 **7 天失效**

## 一、为什么必须这么做（事实约束）

| 事实 | 影响 |
|------|------|
| iOS 应用只能由 Xcode（macOS）编译 | Windows 上无法 `flutter build ios`，必须借 macOS：本机、云 Mac，或 GitHub Actions 的 macOS runner |
| 自签 App 必须用 Apple ID 换取开发证书 | 免费账号证书 **7 天**过期、同时最多 3 个自签 App、只能装自己设备 |
| iOS 16+ 首次运行自签 App 要开「开发者模式」 | 不开启会直接闪退/无法启动，这一步最容易被漏掉 |
| TestFlight 需要付费开发者账号（$99/年） | 免费账号**没有** TestFlight，只能自签 |

## 二、落地内容

- `ios/`：Flutter 3.47 模板，iOS 15.0，Bundle ID `com.hotshow.hotshow`；
  - `Info.plist`：`NSAppTransportSecurity.NSAllowsArbitraryLoads`（采集站多为 http）、
    `UIBackgroundModes=audio`、`CFBundleDisplayName=热剧速览`
- `.github/workflows/ios-unsigned-ipa.yml`：`workflow_dispatch` 或推 `v*` tag 触发，
  `flutter build ios --release --no-codesign` → `Payload/Runner.app` → `hotshow-unsigned.ipa` → artifact
- README：「在 iPhone 上运行（没有 Mac 也能装）」：出包 → Apple Devices/iTunes + Sideloadly →
  填 Apple ID 签名 → 手机信任证书 → 开开发者模式；含 7 天限制对照表与常见问题

## 四、A 视角（iOS 构建链路）——主控自查

子智能体超时未返回，以下三条由主控回读代码/工程核实：

1. **产物路径**：`flutter build ios --release --no-codesign` 固定输出
   `build/ios/iphoneos/Runner.app`；工作流已用 `find` 兜底，路径变化时能在日志里看到真实位置。
   `--no-codesign` 在 Flutter 3.47 仍有效（`flutter build ios --help` 在 Windows 上不可用，
   该参数自 1.x 起未改名）。
2. **SPM / CocoaPods**：Flutter 3.47 的 iOS 模板默认走 Swift Package Manager，但 media_kit 系列
   只提供 podspec，Flutter 会自动回退到 CocoaPods 并生成 Podfile；`macos-14/15` runner 预装
   CocoaPods，无需手工 `pod install`。**这条是推断，首次 CI 跑通才算验证。**
3. **平台分支**：`player_page.dart:829-834` 的 `_isDesktop` 只认 windows/linux/macOS，
   iOS 会走移动端控件，不存在把 iPhone 当桌面的问题。

## 五、未验证项与风险（务必先看）

| 项 | 风险 | 建议 |
|----|------|------|
| iOS 首次构建 | media_kit 的 iOS 静态库/最低版本可能在 CI 报错，本机无法预演 | 先在 Actions 跑一次；失败时看 `pod install` 日志与 `media_kit_libs_ios_video` 版本 |
| 签名后的实际运行 | ATS/后台音频/播放器解码在真机上的表现未验证 | 装好后先试：列表能出图 → 详情 → 播放一集 |
| 7 天到期 | 到期打不开，容易被当成「App 坏了」 | 用 AltStore 自动续签，或每周固定重签 |
| 免费账号 3 个上限 | 手机里已有其它自签 App 会装不上 | 先删一个或等过期 |
