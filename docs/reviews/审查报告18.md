## 三、本轮发现与修复

### P0-1 退出播放页后，自动切线路仍会 setState 到已销毁的 State

`lib/pages/player_page.dart` · `_openCurrent` / `_tryNextLiveLine`

自动切换是 fire-and-forget（`unawaited`）。用户在 `_tuneFuture` / `qualityStore.load()`
这两个 await 期间按返回，`dispose()` 先执行；流程恢复后毫无遮挡地调 `setState`，
对已销毁的 State 抛未捕获异常。

**修复**：两个 await 后各加 `if (!mounted) return;`，`_tryNextLiveLine` 开头补 `mounted` 判断。
另外 `_switchEpisode` 开头加 `++_openEpoch`，让用户手动切台时立刻作废正在飞的自动切换流程，
避免两条流程抢同一个播放器。

### P0-2 检测与播放的请求头不一致（「测着能播、用户播不了」的根因）

`tool/live_verify/verify.py` + `lib/pages/player_page.dart` · `_headersFor`

三个不一致叠在一起：

1. 检测用自编的 Android Chrome UA，App 发的是 `kBrowserUserAgent`（Windows Chrome）；
2. 检测不带 Referer，App 的 `_headersFor` 自动补同域 Referer —— 直播 CDN 上
   多一个 Referer 反而常被判盗链；
3. 分片请求在检测脚本里用的是默认 UA，只有主列表回放了源声明的 UA。

**修复**：检测脚本的 UA 换成 `kBrowserUserAgent` 原文；`_headersFor` 在 `isLive` 时
**不再补同域 Referer**；分片与 key 请求复用同一套头。重跑后同一个源的可播率从
「抽样 80%」落到真实的 44%。

### P0-3 只验主列表 + 首片，漏掉两类必然失败

`tool/live_verify/verify.py`

- AES-128 流的 `#EXT-X-KEY` 地址从来没请求过 —— 分片能下、key 拿不到，播到一半黑屏；
- 只验第一个分片 —— 「列表正常、后续分片全死」的直播流完全测不出来。

**修复**：加验 key 地址；分片抽首/中/末三个；master playlist 再下钻一层验子列表。

### P1-4 备用地址只能手动切

`lib/pages/player_page.dart` · `_tryNextLiveLine`（新增）

精选目录里每个台最多 3 个地址，`toResource()` 把它们铺成 3 条线路。
但原来主地址挂了只会显示「播放失败」，要用户自己去切线路 —— 兜底责任推给了用户。

**修复**：起播失败自动顺延到下一条没试过的线路，全试完才报错；
`_liveTried` 保证每条线路只试一次，不会死循环；用户手动选线路/换源时清空它。

### P1-5 复验把网络抖动当成死链

`tool/live_verify/curate.py`

同一批 111 台连跑两次，掉的台不是同一批（第一次丢黄金翡翠/beIN，第二次丢海南卫视/网球频道）。
按「复验失败就删」会误杀好台。

**修复**：复验失败但首轮通过过的台**保留**（首轮已经过了 key + 三片那套严格检查），
只把主地址换成复验能通的那条。

## 四、扩展性分析

### 目标：频道表热更新（不发版）

| 项 | 内容 |
| --- | --- |
| **现状** | 目录编译进 assets，改一次要发一次版 |
| **阻碍** | `LiveCatalog.load()` 只读 assets，没有远程覆盖入口 |
| **最小改动** | 加 `LiveCatalogStore`：启动时先读 assets，再尝试拉一个约定的远程 JSON（同结构），成功后写本地缓存并优先用缓存；失败静默回退 |
| **改动面** | 新增一个 store + `live_page` 改读 store，约 80 行 |

### 目标：收藏频道 / 最近观看

| 项 | 内容 |
| --- | --- |
| **阻碍** | 直播不写播放历史（`isLive` 在 `_saveProgress` 直接 return），现在没有任何「看过什么」的记录 |
| **最小改动** | 新增 `live_store.dart`（`ChangeNotifier` + SharedPreferences，存 `name + url`）；直播页顶部加「收藏」Tab；播放成功后记一条最近观看 |
| **改动面** | 新 store + `live_page` 加一个 Tab + `PlayerPage` 在 `isLive` 成功起播时回调一次 |

### 目标：EPG 节目单

精选目录里没有 `tvg-id`（生成时丢了）。要做节目单得在 `curate.py` 里
从源数据把 `tvg-id` 一起带出来，再拉 XMLTV 按 id 匹配。工作量中等，但体育台最需要这个。
