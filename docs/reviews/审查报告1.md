附带修复（同一批审查提出、顺带落地）：

- `SubtitleService` 与页面双入口：下载/导入后由 service 负责 `store.select`，`apiKey` 默认读 store，页面不再手传；
- 搜索缓存加 40 条上限；下载同一候选加 in-flight 去重；
- `SubtitleStore`：淘汰旧字幕时 `await` 删除、`load()` 成功后才置 `_loaded`、`select` 相同值不重复落盘；
- 网格：字号上限 1.3 → 1.6、单元格高度加 2px 余量、极小宽度下 `itemWidth` 钳到 1，避免负 `mainAxisExtent`；
- GBK 判定阈值 0.05 → 0.12（西文文件不会被判成 GBK）。

## 二、误报与「部分成立」

1. **「`history_page` 未扣左右内边距，列宽与另两页不一致」——误报。**
   `HistoryPage` 的 `LayoutBuilder` 位于 `padding: EdgeInsets.all(16)` 的 `ListView` 内部，
   `box.maxWidth` 已经是扣过 32px 的可用宽度，且内层 `GridView` 的 `padding` 为 0，与另外两页口径一致
   （`pages/history_page.dart:73`）。
2. **「`sub-add` 轨道会无限堆积」——部分成立。** 调整偏移改用 `sub-delay` 后，微调不再新增轨道；
   但「换一条字幕」仍会 `sub-add` 一条新轨道（旧外部轨道留在 mpv 轨道列表里，不影响播放，仅列表变长）。
   彻底解决需要记录 track id 并 `sub-remove`，列入 P3。
3. **「store 通知在 `_opening` 期间会永久丢失」——部分成立。** `_openCurrent` 结束时会重新读
   `_subtitle` 并挂载，绝大多数情况不会丢；仍补了 `_pendingSubtitleApply` 兜住 apply 之后、
   `finally` 之前那一小段窗口。

## 四、扩展性分析

**目标 1：再接一个中文字幕源（SubHD / Assrt / 自建 API）**

- 当前阻碍：`SubtitleService` 直接持有 `OpenSubtitlesSource`；`SubtitleCandidate` 带 `legacyId/fileId`
  这类源专有字段；UI 文案写死「OpenSubtitles」。
- 最小改动路径：抽 `abstract class SubtitleSource { id, name, search(), download() }`，
  专有字段收进 `Map<String, dynamic> extras`；`SubtitleService` 持有 `List<SubtitleSource>`，
  按 `candidate.source` 路由；UI 增加来源标签。
- 改动面：`models/subtitle.dart`、`services/subtitle/`（新增一个源文件）、`subtitle_service.dart`、
  `subtitle_page.dart`。约 300 行以内，不动播放器。

**目标 2：本地字幕文件**

- 当前阻碍：Android 需要 SAF/文件选择器，工程没有相关依赖。
- 最小改动：加 `file_picker`，`SubtitleService.importFromFile(path)` 复用现有 `_saveArchive`
  （解包/转码/落盘/记住选中都已经具备）。
- 改动面：`pubspec.yaml`、`subtitle_service.dart`（1 个方法）、`subtitle_page.dart`（1 个按钮）。

**目标 3：字幕字号 / 描边 / 位置**

- 现在已有 `NativePlayer.command` 的用法（`sub-delay`），加 `sub-font-size`、`sub-border-size` 是同一路径；
  偏好存 `SubtitleStore`，播放页 `_applySubtitle` 时下发。
- 改动面：`player_page.dart`、`subtitle_store.dart`、`subtitle_page.dart`（设置区）。

**目标 4：按 IMDb/TMDB 精确匹配字幕**

- 当前阻碍：豆瓣接口不提供 IMDb id，只有片名+年份。
- 最小改动：字幕页允许手填 IMDb id（OpenSubtitles 支持 `imdb_id` 参数）；要自动化则需引入 TMDB 搜索（需 Key）。
- 改动面：`subtitle_page.dart`（输入项）、`open_subtitles.dart`（参数）。

**目标 5：双语/第二条字幕轨**

- 当前阻碍：mpv 同时只显示一条 `sid`，media_kit 未封装 `secondary-sid`。
- 最小改动：用 `NativePlayer.command(['set','secondary-sid',...])`，或先按时间轴合并两份字幕再挂一条。
- 改动面：`subtitle_service.dart`（合并/第二轨）、`player_page.dart`。
