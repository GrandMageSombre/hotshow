## 二、自查清单

| 检查项 | 结论 |
|--------|------|
| 链接是否写死错地址 | `LegalNotice.repoUrl` 与 README 里的地址一致：`https://github.com/GrandMageSombre/hotshow` |
| 点击按钮在无浏览器/无插件时会不会崩 | `launchUrl` 包在 try/catch 里，返回 false 或抛异常都只弹 SnackBar，不抛到 UI；`ScaffoldMessenger.maybeOf` 避免无 Scaffold 时报错 |
| 声明弹窗变高会不会把底部开关挤出屏幕 | 开关是固定底栏（不在滚动区），360×800 用例仍通过 |
| 文案是否与「禁止商用」的立场冲突 | 只邀请 Star（免费、非商业），未引导任何付费/打赏，不构成商业行为 |
| 是否泄露隐私 | 打开的是公开仓库地址，不带任何用户标识 |
| 测试是否真的会挡住回归 | 三条断言分别校验「地址」「Star 文案」「按钮」，删掉任一处都会挂 |

- `url_launcher` 在极端环境下（无浏览器）只能给提示，符合预期。
